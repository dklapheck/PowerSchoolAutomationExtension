    Student Connection Call (SCC)

    For new handoffs, Type, Subtype, the three date controls, and Attempt 1–6 tags come from the roster’s Instructions and Settings tab. If an SCC row has blank Type/Subtype values, choose them manually on the PowerSchool New Log page. Saved browser choices below apply only to older handoffs. The extension never submits the log.

    Temporary form settings captures

    On each PowerSchool New Log page, choose the actual form settings and open Capture PowerSchool settings. Use Copy Date Field Map and Copy Attempt Tag Map, pasting each diagnostic into column J of a separate empty PowerSchool Settings Log row. They copy identifiers and labels, not entered dates, student information, or notes. Capture does not submit a log.

    Paste each copied row into the next empty row of the PowerSchool Settings Log. Use Copy row below if the first clipboard attempt failed.
